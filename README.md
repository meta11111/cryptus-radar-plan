План следующей версии Радара, 23.10.2026: 12 этапов, роли инструментов, редакционная основа, сбор, отбор, исследования, пакет автору, форматы, обратная связь и сценарный бюджет.

Обновление по двум артефактам и презентации стратегии Лео: отбор через конкретный вопрос и пользу читателя, аудитория и целевая площадка, одно досье с несколькими возможными углами, доказательства по утверждениям и стык с существующим автором. В сценарный бюджет добавлены токены редакционной карточки; массовые исследования и видеопроизводство вынесены отдельно. Полные внутренние материалы не публикуются.

Статическая информационная страница. Не подключается к рабочему кабинету, базе или платным API. Карта и калькулятор работают в браузере без внешних библиотек; переключатели ничего не запускают и не меняют лимиты аккаунтов.

Публикация через GitHub Pages из `main / root`. Материалы общедоступны. Ключей, данных кабинета, внутренних планов, расшифровок и технических отчётов в публикации нет. Рабочий Радар и Netlify этим сайтом не обновляются.

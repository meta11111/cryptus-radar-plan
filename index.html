Лимиты должны ограничивать именно реальные данные

Reddit: у выбранного Actor лимит действует на каждое сообщество отдельно. Задаём 20 постов на каждое из 5 сообществ — суммарно до 100. Комментарии — отдельным общим бюджетом до 40, без полной выгрузки всех веток. Каждый комментарий тоже оплачивается.

X: смотрим количество полученных постов в usage, а не только число сохранённых карточек. Повторы и контекст веток расходуют бюджет; свободный многократный поиск не включаем. Ограничение одной операции уточняем прогоном.

Рейтинг: пропущенные признаки не заменяем догадками. Показываем покрытие данных; при покрытии внешней оценки ниже 50% точный итог не считаем. Такая тема может попасть в отдельные «находки на проверку».

Как поймём, что фильтрация работает

Проверки до автоматического запуска

  • Один пост дважды → одна запись.
  • Неразрешённый автор из ветки X → пропуск.
  • Реклама с явной меткой → исключение.
  • Разбор мошенничества со словом «скам» → не исключается по слову.
  • Нет метрик или источника → нет выдуманных цифр и подтверждений.

Две реальные подборки

  • Из первых 10 рекомендаций минимум 6 подходят редакции.
  • Не меньше 3 тем в неделю Никита берёт в работу.
  • Для каждого исключения есть код причины.
  • Фиксируем реальную стоимость и пропуски источников.
  • Если качество низкое, сначала меняем источники и анкету, не увеличиваем объём.

Это критерии приёмки, не обещание «только залетающих тем». Работающая система должна уметь показать меньше рекомендаций и честно сообщить о нехватке данных.

Как проверяем сами источники

Reddit: сообщество ещё не гарантия

Отбираем сообщества и рубрики с исследованиями, историями, техническими вопросами и содержательными обсуждениями. Исключаем ежедневные ценовые чаты, мем-поток, рекламу и розыгрыши. У источника просматриваем 10–20 последних публикаций.

X: авторы вместо общей ленты

Исследователи, специалисты по безопасности, разработчики и сильные авторы. Нужны первичные находки, доказательства и объяснения. Один большой охват или число подписчиков не дают источник в белый список автоматически.

Почему не будем пропускать интересные маленькие находки

Из 25 кандидатов оставляем до 5 мест для малоизвестных, но содержательных первичных находок. Ссылки на документы, данные и новый факт могут быть важнее большого числа лайков. Отсутствие реакций не равно плохой теме.

Что происходит с сомнительными фактами и повторами

Одинаковая история объединяется в одну тему. Перепечатки не считаются независимыми подтверждениями. Для спорного утверждения показываем автора и статус проверки; без подтверждения не выдаём его за факт. Материал без проверяемого источника не попадает в готовые рекомендации.

Что если источник не отвечает или заканчивается бюджет

Остальные источники продолжают обработку, в выдаче виден пропуск и время сбора. Повторяем только неудавшуюся часть один раз. Перед каждой платной задачей проверяем остаток; при недостаточном запасе новый сбор не запускаем. Финальная сумма одного уже запущенного запроса может отличаться от оценки.

Это веса оценки одной темы. Они не делят время работы, бюджет или количество площадок. Список площадок и источников выбирается раньше.

Внешний интерес: 0–100

  • Насколько содержательно обсуждают тему.
  • Сильнее ли пост обычного для этого источника — если хватает сопоставимых данных.
  • Насколько тема свежая и живая.
  • Есть ли независимое обсуждение на других источниках.
Один замер не показывает скорость роста. Если данных не хватает, оценка предварительная; модель не выдумывает показатели.

Ценность CRYPTUS: 0–100

  • Подходит ли аудитории: крипта, деньги, безопасность, технологии, люди.
  • Есть ли неожиданный факт, конфликт, герой или полезный вывод.
  • Хватает ли фактов и проверяемых материалов.
  • Есть ли новый угол; не публиковали ли уже такое.
Grok оценивает по одной анкете и объясняет вывод ссылками. Числа — редакционная гипотеза, не прогноз вирусности.

Технические границы нейросети

Один пакет до 25 кандидатов, максимум 2000 символов текста на кандидата плюс ограниченные комментарии. Один основной запрос оценки и максимум одна повторная попытка при ошибке. Ответ по строгой схеме: ID кандидата, оценки критериев, причины, использованные ID источников и статус проверки фактов.

У оценщика нет инструментов поиска, доступа к секретам или возможности публиковать. Тексты постов — данные, а не команды. Проверяем диапазоны оценок и ссылки на существующие входные ID. Не принимаем придуманные URL, просмотры и цитаты. Кэш по содержимому и версии анкеты исключает повторную оплату неизменённого материала.

Схема ответа проверяется кодом, но сама по себе не гарантирует истинность выводов. Если модель недоступна или ответ некорректен, показываем кандидатов с пометкой «смысловая оценка не выполнена», не подменяем её готовым рейтингом. Структурированные ответы Grok.

Как «учится» радар без нагрузки на Лео

  1. Я составляю короткую анкету из уже обсуждённых требований и публикаций CRYPTUS.
  2. Лео даёт 3 хороших и 2 плохих примера с коротким пояснением. Если всё уже есть, я подбираю примеры сам, Лео только подтверждает.

  4. По итогам двух выпусков корректируем источники и анкету; параметры не меняются сами без проверки.
  5. Опубликованные темы связываются с настоящими результатами постов. Отдельное обучение модели — возможное позднее улучшение, не условие запуска.

Еженедельный сбор всего недельного потока может стоить почти столько же, сколько ежедневный. Поэтому ограничиваем число источников, публикаций, комментариев и запросов Grok.

Как передать документ без сайта

Интерактивная версия: отправить этот HTML-файл Лео, он скачает и откроет в обычном браузере. Переключатели и расчёты работают без интернета.

Версия по ссылке: положить подготовленный Markdown в Secret Gist. Там читаются текст, таблицы и раскрываемые блоки; собственные скрипты HTML не запускаются. Secret означает отсутствие в обычном поиске, а не приватность: ссылку может открыть любой получивший её. Закрытый репозиторий требует приглашения Лео и входа в GitHub.

Для интерактивной ссылки подходит GitHub Pages: отдельный публичный репозиторий только с этим документом, без кабинета, его базы и ключей. На бесплатном тарифе Pages работает с публичными репозиториями; это публичная страница, а не закрытый доступ по ссылке. Можно попросить поисковики не индексировать страницу, но это не защита доступа.
